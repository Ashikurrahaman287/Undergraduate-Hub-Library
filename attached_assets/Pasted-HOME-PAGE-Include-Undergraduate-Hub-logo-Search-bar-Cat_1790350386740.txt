14. SMS / EMAIL ARCHITECTURE
Design the system so external notification providers can be integrated later.
Do NOT hard-code an SMS provider.
Create a notification service abstraction.
Example:
sendNotification()
Possible future providers:
SMS provider
Email provider
WhatsApp
For the initial version, internal notifications are mandatory.
Email notifications may be implemented using a server-side email provider.
IMPORTANT SECURITY RULE:
Never expose an email account password or SMTP credential in frontend code.
All email credentials must exist only in secure server-side environment variables.
